# Foxy 26.1 Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Minecraft 26.1.2 module to Foxy that loads Voxy 0.2.16-beta on NeoForge against an un-downgraded Sodium 0.9.1.

**Architecture:** Version-agnostic Foxy sources move to a shared `common/` directory compiled into every version module; the two places 26.1 and 26.2 differ hide behind a `VoxyCompat` service interface. Voxy 0.2.16 targets Sodium 0.8.x, so the 26.1 module adds a compatibility layer: an ASM pass (in shared code, no-op when its patterns are absent) rewrites two mixin annotations inside Voxy's jar, and two Foxy mixins at `priority = 2000` supply the behaviour Voxy's own mixins can no longer provide.

**Tech Stack:** Java, Gradle with the `dev.prism` plugin, NeoForge 26.1.2.84 (FML 11.0.15), Sponge Mixin, ObjectWeb ASM, JUnit 5.

## Global Constraints

- Target Minecraft **26.1.2**, NeoForge **26.1.2.84**, FML loader **11.0.15**.
- Sodium stays at **0.9.1** (`mc26.1.2-0.9.1-neoforge`). Do not downgrade Sodium, Iris, sodium-extra or Reese's.
- Voxy is **0.2.16-beta**; voxy-extra **0.1.7**; Voxy World Gen V2 **2.2.4**.
- Voxy is All-Rights-Reserved and is **never redistributed**. Foxy reads and patches it at runtime only.
- Foxy mixins that touch classes Voxy also mixes into MUST declare `priority = 2000` so they apply after Voxy's (default `1000`).
- All Foxy mixins targeting Sodium or Voxy classes MUST set `remap = false` — these are not Mojang-mapped names.
- Foxy-added fields and methods in mixins MUST be `@Unique` and prefixed `foxy$`.
- The existing root `exclude("net/fabricmc/**")` jar rule stays. Never ship a real `net.fabricmc` package.
- Commit messages: subject and body only. **Do not add `Co-Authored-By` trailers.**
- `./gradlew :26.2:build` must keep passing after every task. The 26.2 module is working software and this plan must not regress it.

- [ ] **Step 1: Write the interface**

Create `common/src/main/java/com/leclowndu93150/foxy/compat/VoxyCompat.java`:

```java
package com.leclowndu93150.foxy.compat;

import net.minecraft.client.Minecraft;
import net.minecraft.client.renderer.LevelRenderer;

import java.util.ServiceLoader;

/**
 * The two places Foxy's shared code has to name something that differs between Minecraft
 * versions. Voxy renamed its render-system holder interface between 0.2.16 and 0.2.18, and
 * Minecraft 26.2 moved the receiver of {@code allChanged()} off {@code Minecraft.levelRenderer}.
 * Everything else Foxy touches is identical across both.
 */
public interface VoxyCompat {

    /** Casts to Voxy's render-system holder interface, whatever it is called this version. */
    void shutdownRenderer(LevelRenderer levelRenderer);

    /** Forces a full renderer rebuild, on whichever object owns that call this version. */
    void markAllChanged(Minecraft minecraft);

    static VoxyCompat get() {
        return Holder.INSTANCE;
    }

    final class Holder {
        private static final VoxyCompat INSTANCE =
                ServiceLoader.load(VoxyCompat.class, VoxyCompat.class.getClassLoader())
                        .findFirst()
                        .orElseThrow(() -> new IllegalStateException(
                                "Foxy: no VoxyCompat implementation found; the version module "
                                        + "did not ship its META-INF/services entry"));

        private Holder() {}
    }
}
```

```java
package com.leclowndu93150.foxy.loader;

import org.junit.jupiter.api.Test;
import org.objectweb.asm.tree.AnnotationNode;
import org.objectweb.asm.tree.ClassNode;
import org.objectweb.asm.ClassReader;

import java.io.InputStream;
import java.util.List;

import static org.junit.jupiter.api.Assertions.assertEquals;
import static org.junit.jupiter.api.Assertions.assertNotNull;
import static org.junit.jupiter.api.Assertions.assertNull;
import static org.junit.jupiter.api.Assertions.assertSame;
import static org.junit.jupiter.api.Assertions.assertTrue;

class VoxySodiumCompatPatchTest {

    private static final String REDIRECT = "Lorg/spongepowered/asm/mixin/injection/Redirect;";

    private static byte[] readClass(String internalName) throws Exception {
        try (InputStream in = VoxySodiumCompatPatchTest.class.getClassLoader()
                .getResourceAsStream(internalName + ".class")) {
            assertNotNull(in, "not on the test classpath: " + internalName);
            return in.readAllBytes();
        }
    }

    private static ClassNode parse(byte[] clazz) {
        ClassNode node = new ClassNode();
        new ClassReader(clazz).accept(node, 0);
        return node;
    }

    /** Finds the @Redirect annotation on the named method, or null if it has none. */
    private static AnnotationNode redirectOn(ClassNode node, String methodName) {
        for (var method : node.methods) {
            if (!method.name.equals(methodName)) continue;
            List<AnnotationNode> annotations = method.visibleAnnotations;
            if (annotations == null) continue;
            for (AnnotationNode annotation : annotations) {
                if (REDIRECT.equals(annotation.desc)) return annotation;
            }
        }
        return null;
    }

    /** The first @Redirect anywhere in the class, whatever its handler is named. */
    private static AnnotationNode anyRedirect(ClassNode node) {
        for (var method : node.methods) {
            List<AnnotationNode> annotations = method.visibleAnnotations;
            if (annotations == null) continue;
            for (AnnotationNode annotation : annotations) {
                if (REDIRECT.equals(annotation.desc)) return annotation;
            }
        }
        return null;
    }

    /** Reads the single string in the annotation's "method" array value. */
    private static String methodValue(AnnotationNode annotation) {
        for (int i = 0; i < annotation.values.size(); i += 2) {
            if ("method".equals(annotation.values.get(i))) {
                return (String) ((List<?>) annotation.values.get(i + 1)).getFirst();
            }
        }
        return null;
    }

    @Test
    void appendsUniformBufferManagerToUploadResultsRedirect() throws Exception {
        byte[] original = readClass("me/cortex/voxy/client/mixin/sodium/MixinRenderRegionManager");

        AnnotationNode before = anyRedirect(parse(original));
        assertNotNull(before, "precondition: the shipped jar should carry a @Redirect");
        assertTrue(methodValue(before).endsWith("Ljava/util/Collection;)V"),
                "precondition: the shipped jar should carry the Sodium 0.8 descriptor");

        AnnotationNode after = anyRedirect(parse(VoxySodiumCompatPatch.patch(original)));
        assertNotNull(after, "the annotation must survive; only its descriptor changes");

        assertEquals(
                "uploadResults(Lnet/caffeinemc/mods/sodium/client/gl/device/CommandList;"
                        + "Lnet/caffeinemc/mods/sodium/client/render/chunk/region/RenderRegion;"
                        + "Ljava/util/Collection;"
                        + "Lnet/caffeinemc/mods/sodium/client/render/chunk/UniformBufferManager;)V",
                methodValue(after));
    }

    @Test
    void stripsTheRedirectFromUpdateOnUpload() throws Exception {
        byte[] original = readClass("me/cortex/voxy/client/mixin/sodium/MixinRenderSectionManager");
        assertNotNull(redirectOn(parse(original), "voxy$updateOnUpload"),
                "precondition: the shipped jar should carry the @Redirect");

        byte[] patched = VoxySodiumCompatPatch.patch(original);

        assertNull(redirectOn(parse(patched), "voxy$updateOnUpload"),
                "the @Redirect must be gone so Foxy's replacement is the only one");
    }

    @Test
    void leavesUnrelatedClassesByteIdentical() throws Exception {
        byte[] original = readClass("me/cortex/voxy/commonImpl/VoxyCommon");
        assertSame(original, VoxySodiumCompatPatch.patch(original),
                "a class with none of the patterns must come back untouched");
    }
}
```

- [ ] **Step 4: Write the ASM pass**

Create `common/src/main/java/com/leclowndu93150/foxy/loader/VoxySodiumCompatPatch.java`:

```java
package com.leclowndu93150.foxy.loader;

import org.objectweb.asm.AnnotationVisitor;
import org.objectweb.asm.ClassReader;
import org.objectweb.asm.ClassVisitor;
import org.objectweb.asm.ClassWriter;
import org.objectweb.asm.MethodVisitor;
import org.objectweb.asm.Opcodes;

/**
 * Adapts Voxy 0.2.16's Sodium mixins to Sodium 0.9.
 *
 * <p>Voxy 0.2.16 is the newest build for Minecraft 26.1.2 and targets Sodium 0.8.x. Two of its
 * Sodium mixins name method descriptors that 0.9 changed:
 *
 * <ul>
 *   <li>{@code RenderRegionManager.uploadResults} gained a {@code UniformBufferManager}
 *       parameter. The redirect only wraps {@code Math.toIntExact} and is semantically inert,
 *       so widening the descriptor is enough.
 *   <li>{@code RenderSection.setInfo} changed its return from {@code boolean} to an {@code int}
 *       bitmask. Voxy's handler never returns the value it received, so it cannot simply be
 *       re-typed — the annotation is dropped here and Foxy's own redirect, which preserves the
 *       bitmask, takes over. See {@code FoxyMixinRenderSectionManager}.
 * </ul>
 *
 * <p>Every rewrite is keyed to a descriptor that only Voxy 0.2.16 contains. A jar without them —
 * 0.2.18 on 26.2, or any future build — comes back byte-identical, so this stays inert rather
 * than corrupting a Voxy that no longer needs it.
 */
public final class VoxySodiumCompatPatch {

    private static final String REDIRECT = "Lorg/spongepowered/asm/mixin/injection/Redirect;";

    private static final String REGION_MANAGER_MIXIN =
            "me/cortex/voxy/client/mixin/sodium/MixinRenderRegionManager";
    private static final String SECTION_MANAGER_MIXIN =
            "me/cortex/voxy/client/mixin/sodium/MixinRenderSectionManager";

    private static final String UPDATE_ON_UPLOAD = "voxy$updateOnUpload";

    private static final String UPLOAD_RESULTS_SODIUM_0_8 =
            "uploadResults(Lnet/caffeinemc/mods/sodium/client/gl/device/CommandList;"
                    + "Lnet/caffeinemc/mods/sodium/client/render/chunk/region/RenderRegion;"
                    + "Ljava/util/Collection;)V";

    private static final String UPLOAD_RESULTS_SODIUM_0_9 =
            "uploadResults(Lnet/caffeinemc/mods/sodium/client/gl/device/CommandList;"
                    + "Lnet/caffeinemc/mods/sodium/client/render/chunk/region/RenderRegion;"
                    + "Ljava/util/Collection;"
                    + "Lnet/caffeinemc/mods/sodium/client/render/chunk/UniformBufferManager;)V";

    private VoxySodiumCompatPatch() {}

    /**
     * @return the rewritten class, or {@code clazz} itself when nothing matched
     */
    public static byte[] patch(byte[] clazz) {
        ClassReader reader = new ClassReader(clazz);
        String name = reader.getClassName();

        boolean isRegionManager = REGION_MANAGER_MIXIN.equals(name);
        boolean isSectionManager = SECTION_MANAGER_MIXIN.equals(name);
        if (!isRegionManager && !isSectionManager) {
            return clazz;
        }

        ClassWriter writer = new ClassWriter(0);
        Rewriter rewriter = new Rewriter(writer, isRegionManager, isSectionManager);
        reader.accept(rewriter, 0);
        return rewriter.changed ? writer.toByteArray() : clazz;
    }

    private static final class Rewriter extends ClassVisitor {
        private final boolean widenUploadResults;
        private final boolean dropUpdateOnUploadRedirect;
        boolean changed;

        Rewriter(ClassVisitor delegate, boolean widenUploadResults, boolean dropUpdateOnUploadRedirect) {
            super(Opcodes.ASM9, delegate);
            this.widenUploadResults = widenUploadResults;
            this.dropUpdateOnUploadRedirect = dropUpdateOnUploadRedirect;
        }

        @Override
        public MethodVisitor visitMethod(int access, String name, String descriptor,
                                         String signature, String[] exceptions) {
            MethodVisitor delegate = super.visitMethod(access, name, descriptor, signature, exceptions);
            boolean dropRedirect = dropUpdateOnUploadRedirect && UPDATE_ON_UPLOAD.equals(name);
            return new MethodRewriter(delegate, widenUploadResults, dropRedirect);
        }

        private final class MethodRewriter extends MethodVisitor {
            private final boolean widen;
            private final boolean dropRedirect;

            MethodRewriter(MethodVisitor delegate, boolean widen, boolean dropRedirect) {
                super(Opcodes.ASM9, delegate);
                this.widen = widen;
                this.dropRedirect = dropRedirect;
            }

            @Override
            public AnnotationVisitor visitAnnotation(String descriptor, boolean visible) {
                if (REDIRECT.equals(descriptor) && dropRedirect) {
                    changed = true;
                    return null;
                }
                AnnotationVisitor delegate = super.visitAnnotation(descriptor, visible);
                if (REDIRECT.equals(descriptor) && widen && delegate != null) {
                    return new DescriptorWidener(delegate);
                }
                return delegate;
            }
        }

        /** Replaces the 0.8 {@code uploadResults} descriptor wherever it appears as a value. */
        private final class DescriptorWidener extends AnnotationVisitor {
            DescriptorWidener(AnnotationVisitor delegate) {
                super(Opcodes.ASM9, delegate);
            }

            @Override
            public void visit(String name, Object value) {
                if (UPLOAD_RESULTS_SODIUM_0_8.equals(value)) {
                    changed = true;
                    super.visit(name, UPLOAD_RESULTS_SODIUM_0_9);
                } else {
                    super.visit(name, value);
                }
            }

            @Override
            public AnnotationVisitor visitArray(String name) {
                AnnotationVisitor delegate = super.visitArray(name);
                return delegate == null ? null : new DescriptorWidener(delegate);
            }

            @Override
            public AnnotationVisitor visitAnnotation(String name, String descriptor) {
                AnnotationVisitor delegate = super.visitAnnotation(name, descriptor);
                return delegate == null ? null : new DescriptorWidener(delegate);
            }
        }
    }
}
```

```java
import com.mojang.blaze3d.buffers.GpuBufferSlice;
import com.mojang.blaze3d.textures.GpuSampler;
import net.caffeinemc.mods.sodium.client.gl.buffer.GlTexelBuffer;
import net.caffeinemc.mods.sodium.client.gl.device.CommandList;

import net.caffeinemc.mods.sodium.client.render.chunk.ShaderChunkRenderer;
import net.caffeinemc.mods.sodium.client.render.chunk.lists.ChunkRenderListIterable;

import net.caffeinemc.mods.sodium.client.render.viewport.CameraTransform;
import net.caffeinemc.mods.sodium.client.util.FogParameters;
import org.spongepowered.asm.mixin.Mixin;
import org.spongepowered.asm.mixin.Shadow;
import org.spongepowered.asm.mixin.Unique;
import org.spongepowered.asm.mixin.injection.At;
import org.spongepowered.asm.mixin.injection.Inject;
import org.spongepowered.asm.mixin.injection.Redirect;
import org.spongepowered.asm.mixin.injection.callback.CallbackInfo;

/**
 * Sodium 0.9 added a {@code GpuBufferSlice} and a {@code GlTexelBuffer} to
 * {@code ShaderChunkRenderer.begin}, carrying the chunk uniforms it moved into a UBO and a texel
 * buffer. Voxy 0.2.16 still calls the three-argument form from the {@code doRender} method its own
 * mixin adds, which would fail at runtime with {@code NoSuchMethodError}.
 *
 * <p>Nothing is fabricated: {@code render} already receives both values, so they are captured
 * there and handed straight back to Sodium.
 *
 * <p>Priority 2000 so this applies after Voxy's mixin, which is what adds {@code doRender}.
 */
@Mixin(value = DefaultChunkRenderer.class, priority = 2000, remap = false)
public abstract class FoxyMixinDefaultChunkRenderer {

    @Shadow
    protected abstract void begin(TerrainRenderPass pass, FogParameters fog, GpuSampler sampler,
                                  GpuBufferSlice uniforms, GlTexelBuffer texels);

    @Unique
    private GpuBufferSlice foxy$uniforms;

    @Unique
    private GlTexelBuffer foxy$texels;

    @Inject(method = "render", at = @At("HEAD"))
    private void foxy$captureUniformBuffers(ChunkRenderMatrices matrices, CommandList commandList,
                                            ChunkRenderListIterable lists, TerrainRenderPass pass,
                                            CameraTransform camera, FogParameters fog,
                                            boolean sorted, GpuSampler sampler,
                                            GpuBufferSlice uniforms, GlTexelBuffer texels,
                                            CallbackInfo ci) {
        this.foxy$uniforms = uniforms;
        this.foxy$texels = texels;
    }

    @Redirect(
            method = "doRender",
            at = @At(
                    value = "INVOKE",
                    target = "Lnet/caffeinemc/mods/sodium/client/render/chunk/ShaderChunkRenderer;"
                            + "begin(Lnet/caffeinemc/mods/sodium/client/render/chunk/terrain/TerrainRenderPass;"
                            + "Lnet/caffeinemc/mods/sodium/client/util/FogParameters;"
                            + "Lcom/mojang/blaze3d/textures/GpuSampler;)V"))
    private void foxy$forwardBegin(ShaderChunkRenderer self, TerrainRenderPass pass,
                                   FogParameters fog, GpuSampler sampler) {
        this.begin(pass, fog, sampler, this.foxy$uniforms, this.foxy$texels);
    }
}
```

### Task 6: Replace Voxy's `setInfo` redirect so Sodium's bitmask survives (Break A)

The reason this whole compatibility layer exists. Task 4 removed Voxy's `@Redirect`; this supplies the corrected one.

**Files:**
- Create: `versions/26.1/src/main/java/com/leclowndu93150/foxy/mixin/sodium/FoxyMixinRenderSectionManager.java`
- Modify: `versions/26.1/src/main/resources/foxy.mixins.json` (`mixins` array)

**Interfaces:**
- Consumes: `VoxySodiumCompatPatch` from Task 4 must have stripped Voxy's `@Redirect` from `voxy$updateOnUpload`, or two redirects will contend for the same call site.
- Produces: nothing other tasks consume.

- [ ] **Step 1: Write the mixin**

This is a port of Voxy's `voxy$updateOnUpload`, reconstructed from its bytecode, with the return value corrected. In 0.8 `setInfo` returned "did anything change"; in 0.9 it returns a bitmask where bit 0 means flags or visibility data changed and bit 1 means the section has culled block entities or animated sprites. Voxy's original discards that value and returns a synthesised boolean, which would clear bit 1 permanently. Here the real value is captured once and returned on every path. The mapping is exact: 0.8 `false` is 0.9 `0`, 0.8 `true` is any non-zero mask.

Create `versions/26.1/src/main/java/com/leclowndu93150/foxy/mixin/sodium/FoxyMixinRenderSectionManager.java`:

```java
package com.leclowndu93150.foxy.mixin.sodium;

import it.unimi.dsi.fastutil.longs.Long2IntOpenHashMap;
import me.cortex.voxy.client.config.VoxyConfig;
import me.cortex.voxy.client.core.IGetVoxyRenderSystem;
import me.cortex.voxy.client.core.VoxyRenderSystem;
import me.cortex.voxy.client.mixin.sodium.AccessorChunkTracker;
import me.cortex.voxy.common.world.service.VoxelIngestService;
import net.caffeinemc.mods.sodium.client.render.chunk.RenderSection;
import net.caffeinemc.mods.sodium.client.render.chunk.RenderSectionManager;
import net.caffeinemc.mods.sodium.client.render.chunk.data.BuiltSectionInfo;
import net.caffeinemc.mods.sodium.client.render.chunk.map.ChunkTrackerHolder;
import net.minecraft.client.multiplayer.ClientLevel;
import net.minecraft.core.SectionPos;
import net.minecraft.world.level.ChunkPos;
import net.minecraft.world.level.LightLayer;
import net.minecraft.world.level.chunk.DataLayer;
import net.minecraft.world.level.chunk.LevelChunk;
import net.minecraft.world.level.chunk.LevelChunkSection;
import net.minecraft.world.level.chunk.status.ChunkStatus;
import net.minecraft.world.level.lighting.LevelLightEngine;
import org.spongepowered.asm.mixin.Final;
import org.spongepowered.asm.mixin.Mixin;
import org.spongepowered.asm.mixin.Shadow;
import org.spongepowered.asm.mixin.Unique;
import org.spongepowered.asm.mixin.injection.At;
import org.spongepowered.asm.mixin.injection.Redirect;

/**
 * Replaces Voxy 0.2.16's redirect of {@code RenderSection.setInfo}.
 *
 * <p>Sodium 0.9 changed that method's return from {@code boolean} to an {@code int} bitmask —
 * bit 0 for "flags or visibility data changed", bit 1 for "section has culled block entities or
 * animated sprites" — and {@code updateSectionInfo} feeds it into {@code renderableSectionTree}
 * membership and {@code sectionsWithGlobalEntities}. Voxy's handler only tests the value it gets
 * and then returns a synthesised {@code true}/{@code false}, so re-typing it would clear bit 1
 * on every path: animated sprites would never register for ticking and culled block-entity
 * tracking would silently drift. {@code VoxySodiumCompatPatch} strips Voxy's annotation and this
 * takes over, preserving the mask while keeping Voxy's ingest behaviour.
 *
 * <p>Voxy's other three injectors on this class target methods 0.9 did not change and are left
 * alone. Priority 2000 so this applies after them.
 */
@Mixin(value = RenderSectionManager.class, priority = 2000, remap = false)
public abstract class FoxyMixinRenderSectionManager {

    @Shadow
    @Final
    private ClientLevel level;

    /**
     * Voxy caches this on the target class too, but it is set from that mixin's constructor
     * injection. Deriving it here instead keeps this mixin independent of application order.
     */
    @Unique
    private int foxy$bottomSectionY = Integer.MIN_VALUE;

    @Unique
    private long foxy$cachedChunkPos = Long.MIN_VALUE;

    @Unique
    private int foxy$cachedChunkStatus;

    @Redirect(
            method = "updateSectionInfo",
            at = @At(
                    value = "INVOKE",
                    target = "Lnet/caffeinemc/mods/sodium/client/render/chunk/RenderSection;"
                            + "setInfo(Lnet/caffeinemc/mods/sodium/client/render/chunk/data/BuiltSectionInfo;)I"))
    private int foxy$updateOnUpload(RenderSection section, BuiltSectionInfo info) {
        boolean hadFlags = section.getFlags() != 0;
        int flags = section.getFlags();

        int result = section.setInfo(info);
        if (result == 0) {
            return result;
        }
        if (hadFlags == (section.getFlags() != 0)) {
            return result;
        }
        flags |= section.getFlags();
        if (flags == 0) {
            return result;
        }

        VoxyRenderSystem renderSystem =
                ((IGetVoxyRenderSystem) this.level.levelRenderer).voxy$getRenderSystem();
        if (renderSystem == null) {
            return result;
        }

        int chunkX = section.getChunkX();
        int chunkY = section.getChunkY();
        int chunkZ = section.getChunkZ();

        if (hadFlags && VoxyConfig.CONFIG.ingestEnabled) {
            Long2IntOpenHashMap chunkStatus =
                    ((AccessorChunkTracker) ChunkTrackerHolder.get(this.level)).getChunkStatus();
            long chunkPos = ChunkPos.pack(chunkX, chunkZ);
            if (chunkPos != this.foxy$cachedChunkPos) {
                this.foxy$cachedChunkPos = chunkPos;
                this.foxy$cachedChunkStatus = chunkStatus.getOrDefault(chunkPos, 0);
            }
            if (this.foxy$cachedChunkStatus == 3) {
                LevelChunk chunk = this.level.getChunkSource()
                        .getChunk(chunkX, chunkZ, ChunkStatus.FULL, false);
                if (chunk != null) {
                    if (this.foxy$bottomSectionY == Integer.MIN_VALUE) {
                        this.foxy$bottomSectionY = this.level.getMinY() >> 4;
                    }
                    LevelChunkSection chunkSection =
                            chunk.getSection(chunkY - this.foxy$bottomSectionY);
                    LevelLightEngine lighting = this.level.getLightEngine();
                    SectionPos sectionPos = SectionPos.of(chunkX, chunkY, chunkZ);
                    DataLayer blockLight = lighting.getLayerListener(LightLayer.BLOCK)
                            .getDataLayerData(sectionPos);
                    DataLayer skyLight = lighting.getLayerListener(LightLayer.SKY)
                            .getDataLayerData(sectionPos);
                    VoxelIngestService.rawIngest(
                            renderSystem.getEngine(), chunkSection, chunkX, chunkY, chunkZ,
                            blockLight == null ? null : blockLight.copy(),
                            skyLight == null ? null : skyLight.copy());
                }
            }
        }

        long packed = SectionPos.asLong(chunkX, chunkY, chunkZ);
        if (hadFlags) {
            renderSystem.chunkBoundRenderer.removeSection(packed);
        } else {
            renderSystem.chunkBoundRenderer.addSection(packed);
        }
        return result;
    }
}
```
